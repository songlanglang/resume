# 交互工牌与在线简历实现方案

## 参考与验证范围

参考地址 https://bytedance.feishu.link/app/app_17gu258rydm ，访问日期 2026-11-11。公开抓取与隔离浏览器均进入飞书妙搭登录页，未获取应用源码，也未观察到登录后的鼠标、拖动或移动端行为。本文记录本次独立重建的完整实现。视觉依据来自用户提供的截图。

截图可确认的元素包括浅蓝网格背景、紫蓝渐变卡头、斜切色块、半透明圆角卡套、金属扣、短挂绳、圆形头像、信息分区、条码、椭圆轨道和悬浮信息气泡。拖拽回弹、指针倾斜、翻面和简历整合由本次设计补充。

## 页面与数据

入口为 /resume/badge/ 。同仓库 /resume/ 是完整简历来源，通过同源 iframe 展示，保留独立阅读和打印入口。工牌显示姓名、定位、任职与入职时间、Token 规模和累计降本。下方展示主观题批改、销售质检、销售教练三个项目，以及独立作品。

数据依据本地主简历《宋恒达-AI产品经理.md》。本页使用主简历已有的模糊化数据，包括日均 40 亿+ Token、累计降本 750 万+ 元、400 万+ 次批改。工牌属于个人职业名片，卡面注明“个人名片”。头像采用姓名字形。联系入口使用已有公开简历邮箱。

## 文件结构

- index.html 负责语义结构、工牌正反面、项目内容、联系入口和完整简历。
- style.css 负责材质、层级、响应式布局与减少动态效果偏好。
- badge.js 负责拖动、弹簧回弹、鼠标倾斜、翻面和简历高度同步。

页面使用原生 HTML、CSS 和 JavaScript。GitHub Pages 直接托管，无构建流程。页面的外部字体加载失败时使用系统中文字体。二维码复用仓库已有资源。

## 工牌物理模型（v1.1）

卡片视为具有质量和转动惯量的二维刚体，中心为质心。上部插槽通过金属扣连接 7 段定长柔性挂绳，顶端固定。挂绳由 Canvas 绘制，路径跟随物理节点弯曲。挂扣的位置和角度由卡片附件坐标变换计算，始终连接卡片。

以 1/120 秒固定时间步长做 Verlet 积分，重力为 1800px/s²。每步迭代 24 次，联合求解绳段距离约束、绳端与卡片附件约束、鼠标与抓取点约束。末端约束计算力矩，卡片转动惯量使用矩形 I=(w²+h²)/12。抓取约束使用 2×2 有效质量矩阵，同时修正平移和角度。

拖动起点转换为卡片局部坐标，抓住中心、边角时会产生不同的转动。指针目标被限制在挂绳和抓取点的最大可达范围。松手移除抓取约束，保留线速度、角速度，重力与绳长约束决定后续摆动。阻尼使运动逐渐停止。为避免剧烈拖动时甩出展示区，摆角限制为 ±0.75 弧度，逐步位移和角速度也有限幅。

渲染层由 badge-motion 管理刚体位姿，badge-flipper 管理正反面翻转。拖动时取消装饰性透视倾斜，以保证可见卡槽与挂扣对齐。翻面按钮使用 aria-pressed，正反面读屏状态同步。

pointer capture 确保拖出卡片仍能继续操作。处理 pointerup、pointercancel、lostpointercapture、窗口失焦、复位和容器尺寸变化。低动态偏好开启时释放即复位。持续低速且接近垂直状态后停止动画循环，避免静止时持续消耗渲染资源。

本模型模拟屏幕平面内的刚体与柔性绳，不含空间扭转、自碰撞和三维绳索。这是本次独立实现的范围，原站因登录限制尚未逐项对照。

## 完整简历与响应式

iframe 加载后测量同源文档 scrollHeight，并使用 ResizeObserver、字体完成回调和窗口 resize 同步高度。完整简历直接读取现有页面，因此其内容更新后自动体现。打印通过独立简历页既有 A4 规则完成。

桌面采用左右分栏。700px 以下改为纵向阅读，工牌居中，项目卡片改为单列。保留可见焦点、语义标题、导航标签与邮箱链接。

## 部署和维护

使用现有 songlanglang/resume 仓库及 .github/workflows/pages.yml。提交 badge 目录并推送 main 后，GitHub Actions 上传站点并部署到 GitHub Pages。

线上地址 https://songlanglang.github.io/resume/badge/ 。更新工牌精选成果时核对主简历。同步更新本地《在线简历清单.xlsx》的版本与日志。不要将本地简历资料和工作簿上传到公开仓库。

核对 JS 语法、页面资源路径、桌面和手机尺寸的横向溢出、翻面按钮状态、拖动后回弹归零、复位、iframe 高度、浏览器运行错误，以及 GitHub Pages 部署结果。作品系统的登录与权限由对应服务控制。
