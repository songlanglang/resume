坚持「先建评测、再上模型」：搭建覆盖静态分析、浏览器 Agent 测试、LLM-as-Judge 的三层自动化评测体系，结合真人双盲评测把「AI 生成得好不好」变成可量化、可迭代的指标（F1 持续 0.9+、人工打标对齐率 87%）——建立从使用数据与真实反馈到策略迭代的数据飞轮。对前沿保持敏感并快速转化商业价值：多模型实测选型（豆包/千问/文心）、DeepSeek 新模型上线后快速验证并完成渠道切换（日均成本 -27.8%）、日常使用 Claude Code / Coze / 妙搭等前沿工具链，并曾以成本模型支撑自建 vs 采购决策。
