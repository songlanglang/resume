📝职业概述

7 年教育产品经验、4 年 AI 应用落地，现任华图教育 AI 产品经理（+1 汇报 CTO），主导 6 个以上 AI 产品从 0 到 1。AI 销售教练面向教育私域销售场景：从业务洞察（结构化销售访谈+历史会话分析）到 Agent 决策编排（Coze 工作流+客户画像+RAG+长短期记忆），再到冷启动验证（试点→灰度→全量推广至 32 分校），累计 35 万次对练、培训成本 -66%、首单成交率 +38%。

诉求校准与边界设计是核心方法论：不是所有销售场景都上 Agent——标准化咨询用规则引擎，个性化对练才引入 Agent，从业务风险与成交价值两个维度拆解，把产品边界收敛为「AI 副驾」接管低风险沟通，高风险/高价值场景交还销售判断。上下文治理有完整实践：设计 Memory 客户记忆（长期个人档案+短期多轮对话+偏好沉淀）+ RAG 业务知识（知识切片+按任务检索+幻觉治理）双路机制，通过证据引用、冲突更新与时效控制保持客户认知准确。

评测体系与 Bad Case 迭代闭环是最大差异化：搭建三层自动化 Grader（静态分析/浏览器 Agent 测试/LLM-as-Judge）+ 真人双盲评测，建立 Golden Case（双人背靠背校验）→ 28 轮验证 → 验证级 → 上线前验证闭环；Bad Case 走智能体分析第一性原理，按理解、检索、记忆、决策四类根因归因，分别驱动 Prompt、RAG、Memory 及策略规则迭代，形成「发现问题→归因修复→回归评测→灰度验证」闭环。F1 持续 0.9+，人工对齐率 87%。
